## What it does

**Log matches. Review performance. Improve — from the phone already in your hand.**

### Ref Mode — post-match film review

Watch the match and code decisions with timestamps. Built for self-review and a development library.

- Timestamped events (tries, penalties, cards, scrums, lineouts, and more)
- Match clock with back-offset timing
- Notes and context on each event
- PDF export for match reports
- Filter and search the log

### Coach Mode — live observation and feedback

Structured notes during a live match, then holistic feedback for developing referees.

- Observation by phase (pre-match, in-match, post-match)
- Focus areas (positioning, communication, game management)
- Timestamped notes on key moments
- Coach report you can share right after the match

### Tech Zone — match operations (beta)

For technical officials and staff, from kickoff to full time.

- Multiple clocks and custom timers
- Roster tracking with smart substitutions
- Live scoring with an event timeline
- Period management (halves, extra time)
- Team colours and customization

Tech Zone is unlocked with a developer gesture. Interested? Email us — or see Support for the tap sequence.

## Why RefLog

**Built for mobile.** Code on the bus. Notes from the sideline. Export before you leave the ground.

**Works offline.** Matches and data stay on the device. No Wi-Fi required.

**Pitch to PDF.** One tap for a report you can send to a coach or keep for yourself.

**Development, not just a logbook.** Track patterns, see strengths, work with coaches.

## Coming soon

Voice-powered logging, cloud sync, and collaboration. Local-only use will still work when those land.
